入力・出力の形式
===

[ykaku.com](http://ykaku.com/ginkokensaku/index.php) が使えなくなった場合でも入力を用意したり、ツールを作り直したりできるように、形式をまとめます。

## 入力ファイル (`ginkositen.txt`)

- 文字コードは Shift_JIS (cp932) で、改行は CRLF です (LF、CR だけでも読めます)。BOM はありません。
- 1 行が 1 件で、空行は無視します。項目は 5 つで、カンマ区切りです。

```text
銀行コード,支店コード,"ｶﾅ","名称",種別
0001,000,"ﾐｽﾞﾎ           ","みずほ",1
0001,001,"ﾄｳｷﾖｳ          ","東京営業部",2
```

| 項目 | 内容 |
| --- | --- |
| 銀行コード | 4 桁の数字です。 |
| 支店コード | 3 桁の数字です。銀行行では `000` です。 |
| ｶﾅ | 半角カタカナと半角英数記号で、15 桁に半角スペースで埋められています。15 桁を超える分は元データの時点で切り捨てられています。 |
| 名称 | 銀行名または支店名です。全角文字を含みます。 |
| 種別 | `1` が銀行行、`2` が支店行です。それ以外はエラーです。 |

ｶﾅと名称は引用符で囲まれています。項目の中にカンマや引用符が入る場合は CSV の規則 (引用符で囲み、引用符は 2 つ重ねる) で読みます。

同梱の 2018 年取得のファイルは 32386 行で、銀行行 1338 件がすべて先に並び、その後に支店行 31048 件が銀行ごとに並んでいます。ツールはこの並びに依存しません。

## 出力ファイル

- 文字コードは UTF-8、改行は LF です。
- 先頭行は `SET NAMES utf8mb4;` で、以降は入力の順に 1 行に 1 つの INSERT 文です (`--rows-per-insert` ではまとめます)。該当する行がないテーブルのファイルは先頭行だけになります。
- 名称はそのまま、ｶﾅは末尾の半角スペースを取り除いて出力します。文字列は `\`、`'`、NUL、改行、CR、Ctrl-Z をバックスラッシュでエスケープします。
- 銀行マスタは `m_banks (bank_code, bank_name, bank_name_kana)`、支店マスタは `m_bank_branches (bank_code, branch_code, branch_name, branch_name_kana)` に INSERT します。
- 出力は入力ファイルだけで決まります (ロケール、タイムゾーン、Python のバージョンに依存しません。タイムゾーンはファイル名の日時にだけ影響します)。
